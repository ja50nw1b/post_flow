# Post Flow - 即時人體姿態偵測

## 簡介
使用 YOLOv8l 進行即時人體骨架偵測，支援 CUDA GPU 加速。
採用鼻子、眼睛、耳朵加權平均進行穩定的頭部追蹤。

## 需求
- Python 3.11+
- NVIDIA GPU（選用，建議使用）
- 攝影機

## 安裝

```bash
# 建立虛擬環境
python -m venv venv

# 啟動虛擬環境（Windows）
venv\Scripts\activate

# 安裝套件
pip install ultralytics torch torchvision opencv-python numpy
```

## 執行

```bash
python realtime_pose.py
```

第一次執行會自動下載 YOLOv8l 模型（約 87MB）。

## 操作
- 按 `Q` 離開

## 功能
- 自動選擇運算裝置（CPU / CUDA GPU）
- 13 個主要關節點偵測
- 頭部位置由鼻子 + 眼睛 + 耳朵加權平均估算
- 移動平均平滑，頭部追蹤更穩定
- 可見度門檻處理遮擋問題

## 關節點
使用 13 個主要關節點：

| 編號 | 名稱 |
|------|------|
| 5  | 左肩 |
| 6  | 右肩 |
| 7  | 左肘 |
| 8  | 右肘 |
| 9  | 左腕 |
| 10 | 右腕 |
| 11 | 左髖 |
| 12 | 右髖 |
| 13 | 左膝 |
| 14 | 右膝 |
| 15 | 左踝 |
| 16 | 右踝 |

## 頭部追蹤
頭部位置由以下關節點加權平均估算：

| 關節點 | 權重 |
|--------|------|
| 鼻子 | 0.1 |
| 左眼 / 右眼 | 各 0.2 |
| 左耳 / 右耳 | 各 0.35 |

## GPU 加速
程式會自動偵測 CUDA，若有 NVIDIA GPU，使用者可以選擇是否使用 GPU 加速推論。
